Cómo usar esta aplicación

  1. Abrí index.html con doble clic en Chrome, Firefox o Edge, sin internet.
  2. En Datos, editá N, tiempos, SKU y cada casilla del layout. Podés importar CSV guardados desde Excel.
  3. Elegí Óptimo exacto, Heurística o Manual y pulsá Calcular y asignar direcciones.
  4. Consultá Resultados para verificar ahorro, trabajo, cálculos y direcciones. En Layout se ven los SKU coloreados.
  5. En Pruebas corré las autopruebas y guardá el CSV para el informe. Imprimí los resultados a PDF con el botón correspondiente.

Columnas de archivos

SKU CSV: SKU;p;d;P;b;c;u;D en ese orden; la primera fila es encabezado. Se admite también separador coma, si los decimales usan punto, o coma decimal con delimitador punto y coma. Layout CSV: matriz sin encabezados; un valor por celda, separado por punto y coma o coma. Excel permite guardar ambas hojas como CSV UTF-8. Importación directa de archivos .xlsx no está disponible en esta versión sin bibliotecas externas.

Reglas económicas

l = max(⌈P / b⌉, c) · s = tr − tp · Bmín = s × p − cr × d · Btodo = s × p (caso D = 0)

Se admite D opcional como extensión: Btodo = s × (p + D), según el criterio del material de trabajo; en el caso común D = 0. El beneficio del modo «mínimo» se mantiene como s × p − cr × d. El trabajo base para la comparación es Σp × tr. Para los datos con D distinto de cero, las extracciones de pallets completos se reportan por separado como extensión y no se incorporan al trabajo base de cajas; por eso el trabajo mostrado es una medida comparativa y puede requerir una base ajustada para una operación real.

Heurística y desempates

Primero se proponen ofertas mínimas con Bmín/l. Una vez que un SKU ya tiene el mínimo, se habilita el bloque indivisible para pasar a todo, de beneficio adicional (Btodo−Bmín)/(u−l). Se acepta la oferta positiva de mayor rendimiento que cabe; después se vuelven a calcular ofertas disponibles. En empates se prefiere mayor beneficio absoluto, luego menor espacio y después el código del SKU. Una oferta de todo desde nada, cuando l = u, se trata como una sola alternativa. Este método es aproximado: la programación dinámica compara todas las opciones factibles con garantía de optimalidad.

Alcance y límites

Modelo didáctico de picking de cajas desde pallets. Cada dirección almacena exactamente 1 pallet y se dedica a un SKU; los pasillos y bloqueos no admiten mercadería. Los tiempos son promedios uniformes dentro de picking; no simula recorridos, fechas de llegada, restricciones de carga, congestión dinámica, niveles reales de existencias ni doble profundidad. P es el inventario entre reposiciones, distinto del volumen semanal d. Las entradas de proveedores se excluyen por ser iguales en todos los escenarios. La selección económica se hace por cantidad de ubicaciones y después se asignan las direcciones físicas; la ubicación concreta no cambia los ahorros del modelo.
